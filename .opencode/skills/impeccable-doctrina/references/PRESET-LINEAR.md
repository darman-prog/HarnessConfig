# Preset High-Craft (opcional)

Arquetipo de partida para `DESIGN.md`. Es un **preset**, no un default: se adopta pidiéndolo y se adapta por tokens al dominio (e-commerce, salud, editorial). El anti-slop de `impeccable` (`craft-floor`) manda sobre este preset.

## Tokens

| Token | Valor |
| --- | --- |
| Superficie | zinc-950 y zinc-900 por capas; elevación con borde de 1px, sin sombras difusas |
| Acento | uno solo: cobalto o ámbar; nunca dos |
| Tipografía | sans de sistema para UI; monospace estricta para métricas, IDs y datos |
| Densidad | filas de 32-36 px; espaciado en escala de 4 |
| Movimiento | 100-150 ms, ease-out; respeta `prefers-reduced-motion` |
| Radio | 6-8 px uniforme |
| Iconos | SVG de línea; prohibido emoji como icono |

## Prohibiciones heredadas de `craft-floor`

Sopa de tarjetas idénticas, gradientes en texto, glassmorphism decorativo, hero-stat genérica y negro puro sin tinte.

## Uso

`inicio-proyecto` o `/impeccable document` lo proponen al crear `DESIGN.md`. Si el proyecto ya tiene su propio mundo visual, no se aplica.
