# Factores de calidad percibida (vocabulario adaptado de SQuaRE)

Vocabulario adaptado, no clausulas de la norma: nombres y mapeo son herramienta de trabajo UX, no certificacion formal. Prohibido afirmar "cumple ISO 25010" sin evaluacion formal completa.

| Factor | Fuente que la alimenta |
| eficacia | observacion (exito de tarea, tiempo) |
| eficiencia | observacion + NASA-TLX |
| satisfaccion | SUS y UMUX-Lite |
| usabilidad_aprendizaje | observacion + QUIS parafraseado |
| proteccion_operador | observacion de error recovery |
| accesibilidad | percepcion (items adaptados); canon y re-auditoria WCAG 2.2 AA en accesibilidad |
| confiabilidad | observacion (errores, fallos) |
| seguridad | percepcion del usuario; no valida seguridad de codigo ni OWASP (delega en seguridad) |
| compatibilidad | frontend-design-review + observacion |

Rendimiento objetivo (performance) y seguridad de codigo NO se miden aqui (de performance y seguridad). Este radar acompaña un informe medido; no es certificacion.
