# Investigación web

Busca evidencia externa fiable para responder preguntas que el repositorio o el contexto disponible no resuelven.

- Delimita la pregunta y la fecha relevante antes de buscar; distingue hechos actuales de conocimiento estable.
- Usa `websearch` para descubrir fuentes y `webfetch` para leer las páginas importantes. Prefiere fuentes primarias: documentación oficial, normas, publicaciones originales y datos del organismo responsable.
- Comprueba que cada fuente respalda la afirmación citada; para hechos importantes, contrasta con otra fuente independiente cuando exista.
- Entrega enlaces directos, título o entidad y fecha de publicación/actualización si está disponible. No inventes citas ni fechas.
- Separa evidencia, inferencias y puntos no confirmados. Indica si una página no se pudo abrir, está desactualizada o contradice otra fuente.
- No envíes información privada del usuario o del proyecto a una búsqueda externa; anonimiza la consulta o pide autorización si es imprescindible.
- Resume solo lo necesario para responder; no conviertas una búsqueda acotada en un informe largo sin pedirlo.
